# Combat study assets

Original first-pass assets generated by
[`tools/combat-art/build_slice.py`](../../../tools/combat-art/build_slice.py)
using Blender 4.5.9 LTS. See the
[authoring notes](../../../tools/combat-art/README.md) for rebuild instructions,
the coordinate/attachment contract and current limitations.

- `traveller-v1.blend` — editable traveller source, with a weighted humanoid skeleton.
- `traveller-v1.glb` — self-contained runtime export, separate from held weapons.
- `waystation-v1.blend` — editable courtyard/masonry/timber source.
- `waystation-v1.glb` — self-contained runtime export.

All meshes and material textures in these files are original outputs of that
script and use the repository's [MIT licence](../../../LICENSE). No third-party
model, texture or animation assets are embedded. The separate generated concept
image is a visual reference and is not embedded in these files.

This is an editable pipeline/articulation proof. It does not yet match the
approved concept's sculpting, material detail or animation quality.
