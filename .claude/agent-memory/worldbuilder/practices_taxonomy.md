## The taxonomy

Practices (long-rest/downtime disciplines, any calling, chosen at level 4/6/8) map to a deliberate domain set, not a grab-bag. Two existing (`core`) + six proposed:

| Practice | Domain | Covers |
|---|---|---|
| Forgecraft (existing) | combat-prep | equipment modification |
| Hearthcraft (existing) | survival/endurance — sustenance | party meals, ability bonus, fatigue |
| Campcraft (proposed) | survival/endurance — security | overnight defense, ambush mitigation, watch rotation |
| Trailcraft (proposed) | exploration/information — terrain | route-reading, hazard-marking ahead of the party |
| Lorecraft (proposed) | exploration/information — artifacts | identification/appraisal of loot, riftborn materials, inscriptions |
| Leechcraft (proposed) | medicine | field wound-tending, poison/disease, non-magical healing |
| Wardcraft (proposed) | arcane/ritual | riftborn-material wards, Void-boundary calibration — NOT divine, no prayer language (GODS.md: no pantheon, no divine casters) |
| Wordcraft (proposed) | social | correspondence, favor-tallying, faction reputation networks |

**Deliberate choice flagged for game-designer:** survival and exploration were each split into two sibling practices (sustenance/security, terrain/artifacts) rather than giving every domain exactly one practice. This was a judgment call, not a forced count — worth confirming it's the right shape before locking mechanics.

## Naming/IP notes

- "Leechcraft" is an archaic real-world English term for the art of healing (a "leech" = healer/physician) — public domain vocabulary, not proprietary D&D terminology. Fits the medieval-frontier register already established.
- "Wardcraft"'s "ritual" framing is flavor language (a practiced procedure), not a pointer to any SRD ritual-casting spell mechanic — flagged so game-designer doesn't conflate it with Scholar's spellcasting.
- None of the six borrow named D&D class features, feats, or proprietary terms.

## Lore constraints applied

- Wardcraft rituals use riftborn-material components and Void-boundary "calibration" language (Vethri risk-management precedent from `docs/world/TECHNOLOGY.md`), never prayer/blessing/divine invocation — see [[established-canon-nexus-verge-world]] and `docs/world/GODS.md` ("no pantheon, no divine casters").
- No practice references Voidborn with intent/hunger/malice language.

**Why:** Practices are the first "universe of X" discipline explicitly requested by design lead using the same coherence bar as damage types/conditions — this taxonomy is the reference shape for any future practice additions (including the later calling-exclusive tier).

**How to apply:** Any new practice proposal should slot into one of these domains or justify a new one, and should follow the naming/register rules above.
