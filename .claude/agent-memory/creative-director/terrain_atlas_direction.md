Terrain art overhaul (2026-08-07 review): grassland + forest (`data/graphics/grassland-cartographic-atlas-v1.png`, `forest-cartographic-atlas-v1.png`) are the locked reference direction for all 42 terrains in `data/terrains.json`. Identity is **hand-drawn painted overland atlas cartography** — deliberately not a DM battle mat (wrong scale metaphor, implies tactical grid — note: this game has no movement grid at all, ADR-014, so "hex-crawl" was retired from this vocabulary 2026-08-09 to avoid implying a hex grid exists or is planned) and not illuminated-manuscript (implies borders/gilding, violates the no-border rule and evokes book-object rather than map-you-stand-inside).

**User reference point (2026-08-09, from the human stakeholder, not an agent call):** likes Judges Guild / West Marches-era hex-crawl poster maps as inspiration, but explicitly *not* the crude flat-block-colour end of that tradition — some of those maps are just solid color fields with minimal linework. The target is their more detailed, illustrated end: hand-painted texture and ink linework carrying the terrain identity, matching what grassland/forest already deliver. Treat "flat block color" as an implicit negative for this direction, same weight as the no-relief-shading rule.

**Why:** Only 2/42 terrains are migrated to `visual.mode: "continuousAtlas"`; the other 40 use legacy `-mai-2.png` images that are a completely different visual language (satellite/relief-map style, cool blue-grey/tan) and structurally wrong — each depicts a whole miniature region with its own baked-in rivers/roads/settlements, so tiling them edge-to-edge repeats the same landmark. Confirmed by viewing `mountain-mai-2.png` directly.

**How to apply:** When reviewing or directing future terrain-art work:
- Forest atlas is on-model but leans more "textural canopy blob" than grassland's crisper ink-glyph cartography — flag if new terrains drift the same way; the ink-linework-over-flat-gouache language is the identity anchor, not just the palette.
- Dramatic/extreme terrain (mountain, ocean/deepWater, lava, ice, ruins) needs a **raised value-contrast and ink-density budget** vs. the calm grassland/forest baseline to avoid going visually boring under the "no scene, no landmark" constraint — drama comes from bolder cartographic glyph shorthand and ink density, never from relief shading, elevation implication, or baked scene composition (that's exactly what made mai-2 wrong).
- Transition-blend risk is real at 40-terrain scale: the organic noise-clip (`shouldOverlayTerrainTransition`/`clipOrganicTransition` in `src/rendering/terrainAtlas.js`) produces a jagged natural edge, not a crossfade, so mushiness risk is more about shared palette/contrast temperature across terrains than the blend mechanism itself. Each terrain needs a distinct hue family + motif glyph + contrast band; `transitionGroup` assignment must follow actual worldgen adjacency data, never geographic guesswork (wrong grouping, e.g. swamp+desert sharing a blend group, would look like mud).
- Built/settlement terrain (town, road, bridge, residential, farmland, industrial) and dungeon-interior tiles are structurally different (built material, inherently landmark-like, don't need infinite world-scale wrap) — open question whether they belong in `continuousAtlas` mode at all or need a separate visual subsystem. Don't assume they follow the same migration path as natural biomes without checking with architect/game-designer first.
- Full brief with priority sequencing (core biome tier first, then water, then dramatic/extreme, then built/dungeon) delivered 2026-08-07; see conversation or re-derive from `tools/image-gen/style-guide.md` "Terrain Art Style"/"Terrain Atlases" sections, which already encode this direction for prompt authoring.
